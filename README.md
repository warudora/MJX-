# MTR Japan Nexus — 規定・参加案内サイト

MJXの参加ガイド・公式規定の案内を公開する静的HTMLリポジトリです。

## ページ構成
- `index.html`: 公式ポータル・規定とMJX紹介への導線
- `regulations.html`: **2026年11月1日承認版を基準とした7規定の一覧・要点・適用状況**
- `jp.html`: MJXの成り立ち・コンセプト・最後に（日本語）
- `en.html`: MJXの成り立ち・コンセプト・最後に（英語参考訳）
- `home.html`: 既存サイト連携用Jinjaテンプレート

| No. | 文書 | 状況 |
|---|---|---|
| 01 | 映画館システム利用ポリシー | 現行・原文維持 |

**重要:** `regulations.html` は規定集の目次・要点案内であり、条文全文ではありません。判断には「MJX 規定集 全7文書（承認版）2026-11-01.pdf」の原文および正式な施行告知を参照してください。とくに第04、第05、第07文書を承認日だけを根拠に施行済みと見なさないでください。

## 公開前の確認
1. PDF全文リンクは `regulations/fulltext/` に配置済み。更新時は原文の一致と7つのリンク先を確認する
2. 第04・05・07文書の施行日が決定した場合に、運営の正式告知を受けてステータスを更新する
3. 英語版は参考説明であり、公式原文は日本語として扱う

`jp.html` / `en.html` の参加ガイドは完全な条文を掲載したものではないため、公式規定集と異なる記述が残った場合は規定原文を優先して確認してください。

## UI・構成（2026年11月）
- `mjx-theme.css` — トップページ、公式7規定、参加ガイド、ホーム用テンプレートに共通する白基調・マゼンタのデザインシステム。
- `index.html` — 公式ポータル。規定と日英ガイドへのカード型導線を提供。
- `regulations.html` — 7規定の適用状態と要点。検索・絞り込み・詳細展開。
- `jp.html` / `en.html` — 歴史・コンセプト・締めの内容のみ残し、旧参加ガイドのルール説明を削除。
- `home.html` — Jinjaテンプレートとしての動的処理は変更せず、規定案内とスタイルを追加。

静的ページは同階層の `mjx-theme.css` を読み込みます。`home.html` はFlask/Jinjaの静的ファイル公開パスが未設定でも基本デザインが表示されるよう、同等のスタイルをテンプレート内に内包しています。今後のテーマ変更時は両方を更新してください。

## 2026-11-01: 旧参加ガイドの整理
- 旧参加ガイドの共通ルール・Builder・Visitor・遊び方・運営対応の説明は、公式7規定と重複するため掲載を終了。

## 規定全文のPDF閲覧
7規定それぞれの「全文を読む」ボタンから、`regulations/fulltext/` にある当該規定のPDFを直接閲覧できます。PDFは「MJX 規定集 全7文書（承認版）2026-11-01」の該当ページを抽出したもので、各規定の表紙も含まれます。OCRで打ち直しておらず、画像化された条文ページもそのまま収録しています。

- 01: 映画館システム利用ポリシー（元の1–3ページ）
- 02: 共通サーバー規定（元の4–8ページ）
- 03: Builder規定（元の9–18ページ）
- 04: リソースパック統一規約（元の19–25ページ）
- 05: プライバシーポリシー（元の26–30ページ）
- 06: 経済規定（元の31–47ページ）
- 07: ビジター向けルール（元の48–50ページ）

文書04・05・07については、改訂・修正の承認と施行を区別する既存の表示を維持しています。

## レスポンシブ対応（2026-11-01）
- PC（1025px以上）: コンテンツの横並びと余白を維持。
- タブレット（701–1024px）: 2列／1列切替、折返しナビゲーションと横スクロールに対応。
- スマホ（700px以下）: 1列カード、100%幅の検索と全文PDFボタン、44px以上の操作領域。
- 小型端末（360px以下）、端末横向き、セーフエリア、操作時のホバー誤動作を考慮。
- 共通CSSを `mjx-theme.css` と `home.html` 埋込スタイルへ同一内容で反映。
