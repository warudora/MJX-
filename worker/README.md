# MJX 規定AIサポーター

このディレクトリには、MTR Japan Nexus（MJX）公式サイトの規定AIサポーターに関連するプログラムが含まれています。

AIサポーターは、公式規定に関する質問の補助と、関連条文への案内を目的としています。回答は運営による正式な判断や規定本文に代わるものではありません。

一般利用者向けの案内は、以下をご覧ください。

- [MJX公式サイト](https://warudora.github.io/MJX-/)
- [公式7規定](https://warudora.github.io/MJX-/regulations.html)
- [公式規定全文](https://warudora.github.io/MJX-/regulations-full.html)

運用・構成・接続設定に関する詳細は、この公開READMEには掲載していません。お問い合わせは[MJX公式Discord](https://discord.gg/PehjWyGDHV)へお願いします。
