🔗 MJXの成り立ち（3つの前身コミュニティのノウハウ統合）

MTR Japan Nexus（MJX）は、これまで異なる分野で発展してきた3つのコミュニティが、それぞれ培ってきた技術・経験・ノウハウを持ち寄ることで誕生した統合都市サーバーです。

単純に既存のワールドを統合したものではなく、各コミュニティが培ってきた「鉄道」「システム・技術」「建築」それぞれの強みを、新たな一つの都市圏へ融合しています。

MJaS

MTR Japan Server

2024年夏頃公開。MTR Japan Usersが運営・管理する大規模な公開MTRサーバー。

800を超える駅と、総延長70km以上の定期運用路線網を構築・運営してきた経験を持ち、大規模な鉄道路線・駅・交通インフラを建設・運用するためのノウハウをMJXへ引き継いでいます。

MTTS

New MTR Technology & Transport Server

NEST氏をはじめとする管理陣が運営。

MTRを活用した路線建設に加え、車内デジタルサイネージなどのシステム構築、交通関連の技術・ギミックの開発、サーバー運用に関するノウハウを培ってきた技術系コミュニティです。MJaSとは異なる規模・方向性での路線建設や、現代日本の交通を再現するための技術的な取り組みを行ってきました。

JNC

JapanitureCraft

Japaniture Modの家具・インテリア技術を軸に、建築・都市景観・内装デザインに関するノウハウを培ってきた建築専門コミュニティです。

リアルで高品質な建築物や内装、都市景観を制作する技術と経験をMJXへ引き継いでいます。

🌐 3つの強みを一つの都市へ

  • MJaS — 大規模な鉄道路線・交通インフラ建設のノウハウ
  • MTTS — 交通システム・技術・路線建設のノウハウ
  • JNC — 建築・都市景観・内装のノウハウ

これら3つの強みを組み合わせることで、MJXでは鉄道だけでも、建築だけでもない、「都市そのもの」を楽しめるMinecraftコミュニティを目指します。

【MJXのコンセプトと目的】

MTR Japan Nexus（以下「MJX」）は、MJaSの鉄道網、MTTSの先端技術・交通インフラ、JNCのリアルな建築・景観を融合し、Minecraft上に「都市・交通・生活・経済」が揃った一つの世界を構築するコミュニティサーバーです。

鉄道・自動車・建築・店舗経営・各種イベントなどを通じて、プレイヤー同士で都市圏を発展させていくことを目的としています。

自由な活動を尊重しつつ、他のプレイヤーの成果物、財産、設備およびサーバー環境の保護を徹底します。

1. 🌐 共通ルール（全プレイヤー適用）

ビルダー・ビジターを問わず、MJXに参加するすべてのプレイヤーに適用される基本ルールです。

1-1. 基本マナー・禁止事項

🚫 他人の建築・財産への配慮

他のプレイヤーが作成・所有・管理している以下のものを、許可なく破壊・移動・使用・持ち去る行為を禁止します。

  • 建築物
  • 道路・線路
  • 車両
  • アイテム・チェスト
  • 自動販売機・ショップ
  • その他の設置設備

故意または悪質な破壊・盗難・荒らし行為には、一発BANを含む厳正な対応を行う場合があります。
過失による損害については、被害状況や経緯を確認したうえで運営が対応します。

⚔️ カオス要素・戦闘（TacZ等）

街中での無差別なPK（プレイヤーキル）、銃撃、爆発、その他の戦闘によって、他プレイヤーの建築物・車両・設備等を巻き込む行為は禁止です。

TacZ等の武器を使用した試射・戦闘・撮影は、指定されたテスト場・撮影エリア・PvPイベント等で行ってください。

イベント等で特別に認められた場合は、そのイベント固有のルールを優先します。

⚡ サーバー負荷への配慮

サーバーの安定した運営を維持するため、以下のような過剰な負荷を発生させる行為は避けてください。

  • 大量のクロック回路の常時稼働
  • 過剰なCreate等の動力・回転機構
  • 大量のエンティティの放置
  • 大量の車両の放置
  • 大量のアイテム・ドロップアイテムの放置
  • その他、サーバーの動作に著しい負荷を与える設備・装置

サーバーへの負荷が大きいと運営が判断した場合、設備の停止・撤去・変更等をお願いする場合があります。

1-2. 💰 経済システム（Lightman's Currency）

MJXでは、サーバー内通貨としてコインを使用します。

🏦 金融・インフラ

街中のATM・銀行等を利用して、以下の金融サービスを利用できます。

  • 預金
  • 引き出し
  • 口座間送金
  • その他、対応する金融サービス

🪙 通貨の入手

ビジターを中心に、以下のような活動によってコインを獲得できます。

  • ビルダー・運営からの業務受託
  • 店舗・サービス業
  • タクシー・バス等の運転
  • 商品・料理等の販売
  • 自動販売機の運営
  • イベント・大会への参加
  • その他、認められた業務・サービス

🛒 通貨の使用

コインは以下のようなサービス・商品に使用できます。

  • MTR等の運賃・定期券
  • 高速道路料金
  • 車両購入
  • 武器・弾薬
  • 家具・家電・インテリア
  • 飲食店・ショップ
  • 物件のレンタル・購入
  • その他、対応する商品・サービス

📉 インフレ防止

健全な経済を維持するため、以下のような形で適切に通貨を回収します。

  • 運賃
  • 高速道路料金
  • 事故修復費
  • 行政上の罰金
  • 各種手数料
  • その他の経済調整

サーバー内経済の状況に応じて、運営が料金・手数料等を調整する場合があります。

1-3. 🚗 道路交通・事故対応（MTS / Kaminari等）

🚨 事故が発生した際の義務と賠償

車両の運転中に事故を起こし、建築物・道路・車両・設備等を破損させた場合は、直ちに安全を確保し、事故を放置せず、速やかに当事者または運営へ報告してください。

【修復・賠償】
被害状況に応じて、運営が復旧方法・修復費等を判断します。原則として当事者同士の話し合いを尊重し、必要に応じて運営が仲介します。

🚫 悪質な事故放置の禁止

事故を起こしたこと自体を理由として、直ちに厳しい処分を行うことは原則ありません。

ただし、以下のような悪質な行為は処分の対象となります。

  • 当て逃げ
  • 故意の事故
  • 事故の隠蔽
  • 虚偽の報告
  • 事故後の意図的な放置
  • 同様の行為を繰り返すこと
1-4. 📹 配信・撮影

YouTube、Twitch等での配信・動画撮影・写真投稿は大歓迎です！

他プレイヤーが映り込む場合は、プライバシーやプレイ環境への配慮をお願いします。

推奨ハッシュタグ： #MJX鯖 #MTRJapanNexus
1-5. ⚠️ サーバー・MOD環境に関する免責

MJXでは多数のMOD・プラグインを使用しているため、以下の事象が発生する場合があります。

  • 予告なしのメンテナンス
  • 仕様変更
  • MOD・プラグイン等による不具合
  • ワールドの復旧・ロールバック
  • データ消失
  • その他、予期せぬ障害

データ損失等が発生した場合、完全な復旧を保証することはできません。

また、本規約に明記されていない事態については、状況を確認したうえで運営が最終的に判断します。

2. 🔨 ビルダー（建築・開発者）向けルール

ビルダーは、MJXにおいて都市開発・建築・交通・インフラ整備等を行う開発者向けの参加区分です。

🏅 2-1. ビルダー資格

所定のMTR Global Server Alliance（MGSA）によるビルダー選考を受け、条件を満たす必要があります。

選考通過後、MJX内で都市開発・建築等を行うための権限が付与されます。

🏗️ 2-2. 建築・開発権限

ビルダーにはクリエイティブ権限が付与され、土地取得申請なしで自由に都市開発を行うことができます。

ただし、他者の既存の建築物・土地・設備・交通インフラ等を無断で変更・撤去する行為は禁止します。

🏗️ 2-3. 建物一覧・Schematic共有

制作した建物をSchematicとして共有し、他のビルダーが都市開発に利用できる「建物一覧」を運用します。

【建物登録の手順】
Discordの「建物一覧」チャンネルへ、以下の形式で投稿してください。
建物名 ＋ 完成写真
例： 🏪 コンビニ ＋ 📷 完成写真

その後、マインクラフトサーバーにてSchematicを保存してください。
保存名は建物名と統一してください。
例： コンビニ.schem

【登録と利用許諾】

「建物一覧」への登録を行った時点で、制作者は以下の利用を許諾したものとして扱います。

MJX内のビルダーが、都市開発を目的として当該Schematicを自由に設置・使用すること。

この利用について、設置ごとの個別許可は不要です。また、都市開発上必要な場合は、同一Schematicを複数箇所へ設置することができます。

【未登録の建物】

「建物一覧」に登録されていない建物については、制作者の許可なくSchematicを使用・設置しないでください。

【建物の改造】

設置場所や都市景観に合わせて、外装・内装・設備等を変更することができます。

ただし、元の制作者の作品性を著しく損なう大幅な改変や、改変した建物を元制作者の作品として扱う行為は避けてください。大幅な改変を行った建物を新たな建物として再登録する場合は、可能な限り元の制作者を明記してください。

【登録解除】

制作者が運営へ申し出ることで、当該Schematicの新規利用を停止することができます。

ただし、登録解除前に既に設置・利用された建物、および既に取得・配置済みのSchematicについては、原則として撤去・回収を行いません。

🚆 2-4. 鉄道・インフラ（MTR Mod）

ビルダーは事前申請なしで路線を敷設することができます。

ルートの重複や並行路線の建設も原則として自由です。

また、長期間開発が停止していることのみを理由として、直ちに路線の権利を剥奪したり、強制撤去したりすることはありません。

ただし、他者の建築物・設備・既存インフラ等を無断で変更・撤去することは禁止します。

⚙️ 2-5. Create Modの扱い

Create Modの建材・装飾・機能等は自由に使用できます。

ただし、以下のようなサーバーへ過剰な負荷を与える設備については、禁止または制限する場合があります。

  • 大型の回転機構
  • 大量のクロック回路
  • 大量のエンティティを使用する設備
  • その他、サーバーの動作に著しい負荷を与える設備

鉄道については、原則としてMTR Modをメインの鉄道システムとして使用します。

💰 2-6. ビルダーの経済関与ルール

【クリエイティブ資源の無制限配布禁止】

ビルダーは、クリエイティブによって生成したアイテム・建材・装備等を、ビジター等へ無制限に直接配布することを禁止します。

また、MJX内の経済バランスを維持するため、ビルダーが保有するコインをビジター等へ無制限に直接配布する行為も禁止します。

【業務委託・公式店舗の推奨】

ビジターへ仕事を依頼し、その対価としてコインを支払うことは歓迎されます。

例：案内、運転手、撮影、建築作業、店舗スタッフ、その他の業務

また、運営の認可を受けた公式店舗・事業の運営も歓迎されます。

例：ショールーム、車両ディーラー、飲食店、ショップ、その他のサービス事業

3. 🚶‍♂️ ビジター（一般参加・生活者）向けルール

ビジターは、MJXの都市で観光・買い物・交通・仕事・生活・イベント等を楽しむ一般プレイヤー向けの参加区分です。

🎮 3-1. 参加環境

ビジターは原則としてアドベンチャーモードで参加します。

そのため、通常のプレイではブロックの破壊や都市施設の改変を行うことはできません。

参加時には、行政から初期手当が支給されます。

💼 3-2. お金の稼ぎ方

以下のような活動によってコインを獲得できます。

  • 接客
  • 運転手
  • 案内
  • 業務受託
  • ショップ経営
  • 商品販売
  • 自動販売機運営
  • イベント・大会への参加
  • その他、認められた仕事・サービス
🛒 3-3. お金の使い道
  • 交通： MTR運賃、定期券、高速道路料金
  • モビリティ： 車両・ディーラー、MTS / Kaminari関連製品
  • 装備： TacZ等の武器・弾薬、その他、対応する装備
    ※武器・弾薬の使用については、MJXの戦闘・安全ルールを遵守してください。
  • 生活： JNC系家具・家電、飲食、ショップ商品、物件の購入・賃貸、その他、対応する商品・サービス
4. 🏙️ 基本的な遊び方
  • 🔨 ビルダー： 都市、住宅、駅、道路、鉄道、店舗、各種施設等を自由に開発する。
  • 🚶 ビジター： 街を歩き、交通を利用し、買い物・仕事・イベント等を通じて都市で生活する。
  • 🚆 交通： MTRに乗車したり、自分で車両を運転したりして都市を移動する。
  • 💰 経済： 仕事でコインを稼ぎ、商品を仕入れ、ショップや自動販売機等を運営する。
  • 📹 コンテンツ制作： 都市での生活・建築・交通・イベント等を配信、動画、写真などのコンテンツとして発信する。
5. ⚖️ 運営による対応

規約違反が確認された場合、違反内容・悪質性・被害状況・過去の違反状況等を考慮し、以下の対応を行う場合があります。

  • 注意・警告
  • 建築物・設備等の修正依頼
  • アイテム・通貨等の回収
  • 権限の一時停止
  • ビルダー権限の停止・取消
  • 一時BAN
  • 永久BAN
特に、以下のような行為については厳重に対応します：

荒らし、盗難、故意の破壊、サーバーへの負荷攻撃、不正な経済操作、その他、サーバー運営を著しく妨害する行為
