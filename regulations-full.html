MTR Japan Nexus 共通サーバー規定

2026 年 10 月 05 日制定

前文

本規定は、MTR Japan Nexus (以下「MJX」という) が運営するサービスの共通利用ルールを定めるものである。

本規定において「本サービス」とは、MJX が運営する Discord サーバー、Minecraft サーバーその他の関連サービスをいう。

各サービスに関する詳細なルールについては、別途定める規定を適用する。

第1条（法令の遵守）

利用者は、日本国内の法令および利用者が居住する地域の法令を遵守しなければならない。

第2条（使用言語）

1. 本サービスでは、日本語および英語の使用を基本とする。

2. 利用者は、他の利用者との円滑な意思疎通に努めなければならない。

3. 運営は、必要に応じて特定のサービスまたはチャンネルにおける使用言語を指定できる。

第3条（迷惑行為等の禁止）

利用者は、以下の行為を行ってはならない。

1. 他の利用者に対する迷惑行為、威圧的な言動、過度な挑発行為

2. 誹謗中傷、暴言、侮辱、差別的な発言

3. 他の利用者や団体を不当に貶める行為

4. 政治的または宗教的な発言、議論、勧誘等、運営が不適切と判断する行為

5. 公序良俗に反する内容、成人向けまたは過度に性的な内容の投稿

6. 他の利用者の活動を妨害する行為

7. その他、運営が迷惑行為または不適切な行為と判断する行為

なお、本人に悪意がなかった場合であっても、行為の内容や影響に応じて処分の対象となることがある。

第4条（個人情報の取り扱い）

1. 他の利用者の個人情報を、本人の許可なく公開してはならない。

2. 自身の個人情報についても、公開する際は十分に注意すること。

3. 個人情報の収集、公開、拡散その他これに類する行為を、運営が不適切と判断した場合は処分の対象とする。

第5条（スパム・危険なコンテンツ等の禁止）

1. スパム行為、過度な連投、無意味なメッセージの大量投稿を禁止する。

2. ウイルス、マルウェアその他利用者やサービスに危害を与える可能性のあるファイル・リンクの投稿を禁止する。

3. R15・R18 相当の内容を含むリンクやコンテンツの投稿を禁止する。リンク先の内容にかかわらず、運営が危険または不適切と判断した場合は削除や処分の対象となることがある。

第6条（広告・勧誘の禁止）

運営の許可なく、営利目的の広告、宣伝、他サーバーへの勧誘、その他これらに類する行為を行ってはならない。

第7条（関係団体・他サーバーに関する取り扱い）

1. MTR Global Server Alliance (以下「MGSA」という) およびその他の関係団体、ならびに他の Minecraft サーバーに関する話題は、運営が指定する場所で行うことを基本とする。

2. 他サーバーで発生したトラブルについて、原則として MJX は関与しない。ただし、MGSA に関係する事案については、この限りではない。

3. MJX 内での行為に限らず、MGSA に関係する活動についても、MJX の運営に重大な影響を及ぼすと運営が判断した場合は、対応の対象となることがある。

4. 必要に応じて、MGSA その他の関係団体と、利用者の違反行為等に関する情報を共有することがある。

5. MGSA において、特定の利用者に対する MGSA 全体BAN が閣議決定された場合、MJX を含む MGSA 加盟サーバーは、当該決定に従い、対象者に対する利用停止等の措置を講じなければならない。

6. 前項の措置は、MGSA 全体 BAN の決定に基づくものであり、各加盟サーバーが独自に判断して適用の可否を決定するのではない。

7. MGSA その他の関係団体における処分等の情報は、運営が必要と判断した場合に参考とすることがある。ただし、MGSA 全体BAN に該当する場合を除き、当該情報のみをもって、直ちに MJX での処分を決定するものではない。

第8条（複数アカウントの使用）

1. 利用者は、複数のアカウント (サブアカウントを含む) を使用して本サービスを利用することができる。

2. 複数アカウントを利用した迷惑行為、処分の回避、その他不適切な行為を禁止する。

3. 運営は、複数アカウントの使用状況が不適切であると判断した場合、利用制限等の措置を行うことができる。

第9条（その他の不適切な行為）

本規定に明記されていない行為であっても、MJX の運営、利用者間の交流、または関係団体との活動に支障をきたすと運営が判断した場合、必要な措置を行うことができる。

第10条（運営者に対する規定の適用）

1. 運営者も、原則として本規定を遵守しなければならない。

2. ただし、最高管理者の承認がある場合、運営者は本規定に抵触する行為を行うことができる。

3. 最高管理者は、自らの判断により、本規定の全部または一部の適用を免除し、または本規定に抵触する行為を行うことができる。

第11条（違反への対応・処分）

1. 利用者が本規定に違反した場合、運営は違反の内容や程度に応じて、以下の措置を行うことができる。

・注意・警告・タイムアウト・一時的な利用停止・永久的な利用停止

2. 処分の内容や期間は、運営が違反の内容、状況、影響等を考慮して決定する。

3. 運営は、必要に応じて複数の措置を組み合わせて実施できる。

4. 処分は、違反者本人に事前通知することなく実施される場合がある。

5. MGSA 全体BAN が閣議決定された場合の措置については、第 7 条の定めに従う。

第12条（異議申し立て）

1. 利用者は、処分について運営に説明を求めることができる。

2. 異議申し立てを行った場合であっても、原則として処分の効力は停止しない。

3. 運営は、申し立ての内容を確認し、必要と判断した場合は処分の変更または撤回を行うことができる。

4. MGSA 全体BAN に基づく措置については、MJX 単独で当該決定を変更または撤回することはできないものとする。

第13条（自動検出システム等）

1. 本サービスでは、Wick 等の自動検出システムを利用する場合がある。

2. 自動検出による処分について、利用者は運営に確認を求めることができる。

3. 誤検知が確認された場合、運営は必要に応じて処分の変更または撤回を行う。

4. アカウントの乗っ取り等、本人の意図しない行為であっても、状況に応じて利用制限等の措置を行うことがある。

第14条（ルールの確認）

利用者は、本サービスの利用にあたり、本規定および運営が別途定めるルールを確認し、遵守しなければならない。

第15条（規定の改定）

1. 運営は、必要に応じて本規定を改定できる。

2. 改定は、原則として事前の通知なく行われる場合がある。

3. 改定後の規定は、公開された時点から適用されるものとする。

第16条（個別サービスの規定）

1. Minecraft サーバーその他の個別サービスについては、本規定に加えて、各サービスで定める個別規定を適用する。

2. 個別規定と本規定の内容が異なる場合、対象となるサービスや行為に応じて、運営が適用する規定を判断する。

3. 利用者は、本規定および各サービスの個別規定を併せて遵守しなければならない。

附則

1. 本規定は、2026年11月1日より施行する。

2. 本規定に定めのない事項については、運営が必要に応じて判断する。

3. 本規定の解釈について疑義が生じた場合は、運営が判断する。

MTR Japan Nexus Builder 規定

2026 年 10 月 26 日制定

MTR Japan Nexus

前文

本規定は、MTR Japan Nexus (以下「MJX」) における Builder の資格、権限、義務および運営手続きを定める。

Builder とは、MJX 内で建築、都市開発、鉄道・交通インフラの整備などを行う者をいう。

MJX は、Builder の自由な開発活動を尊重するとともに、参加者の権利、既存施設、サーバー環境および経済システムを保護する。

本規定は、MJX 共通規定その他の関連規定と併せて適用する。

第1章 総則

第1条（目的）

1. 本規定は、Builder の自由で継続的な開発活動と、MJX 全体の利益を両立させることを目的とする。

2. Builder は本規定および関連規定を遵守し、他の参加者と協力して MJX の発展に努める。

3. 本規定は、正当な理由なく Builder の開発活動を制限するものではない。

第2条（Builder 資格および選考）

1. Builder 資格は、MTR Global Server Alliance (以下「MGSA」) の選考制度、またはMJXが認める手続きを経て取得する。

2. 資格区分、選考方法および活動権限は、MGSA の共通制度および MJX の関連規定に従う。

3. MJX 独自の選考手続きや権限を設ける場合は、その内容と適用条件を別途明示する。ただし、MGSA の制度を MJX の権限を超えて変更してはならない。

4. 資格取得後も、規定違反があれば第 19 条に基づく措置の対象となる。

第3条（Builder の基本的権限）

1. Builder は、MJX 内で建築物、道路、鉄道路線、駅、交通施設、店舗などを開発できる。

2. Builder には、資格区分に応じて開発に必要な権限を付与する。

3. 土地取得の事前申請は原則不要と し、自由な開発を認める。ただし、他者の権利や関連規定による制限は適用される。

4. 他者の開発を不当に妨害したり、既存の建築物、設備、所有物などを無断で変更、移動、撤去、破壊したりしてはならない。

5. 運営は、安全性、公共上の必要性、他者の権利保護のため、合理的かつ必要な範囲で開発を制限できる。

第4条（活動上の義務）

Builder は、次の事項を守らなければならない。

1. 他者の建築物、所有物、設備および開発活動を尊重する。

2. サーバーに過度な負荷をかけないよう努める。

3. 運営から規定違反の確認、設備修正、負荷対策など合理的な協力を求められた場合、必要な範囲で協力する。

4. 自らの活動に問題が発生した場合、速やかに状況を確認し、必要に応じて運営へ報告する。

第5条（運営との関係）

1. Builder に関する通常の判断は、一般管理者その他の権限を持つ運営担当者が行う。

2. 各担当者の権限は、MJX の管理者に関する規定および権限分担に従う。

3. MJX 全体に関する最終的な意思決定は、最高管理者規定に従う。

4. 運営は、関連規定、事実関係、公平性および MJX 全体への影響を考慮して判断する。

5. Builder の権利や活動に影響する措置については、原則として理由を説明する。

第2章 開発および権利の管理

第6条（優先保有権）

1. Builder は、運営の承認により、特定の区域、建築物、路線などに優先保有権を持つことができる。

2. 優先保有権は、他の Builder との開発調整を目的とするものであり、土地の無制限な所有権や、他者の正当な開発を一律に禁止する権限ではない。

3. 優先保有権の申請では、対象範囲、管理者および開発目的を明確にする。承認された権利は運営が記録・管理する。

4. 保有できる範囲・件数、申請・承認方法などの具体的な基準は、運営が別途定めて周知する。

5. 優先保有権のない通常の開発について、第 3 条に定める事前申請不要の原則は維持する。

6. 他の Builder の開発と競合する場合、当事者間の協議を優先し、解決しない場合は運営が既存の権利、開発状況、公共性などを考慮して調整する。

7. 保有者は継続的な開発・管理に努める。進捗には建設、具体的な改修、設計に基づく実質的な作業などを含み、単なる保有宣言や予定表明のみは原則として含まない。

8. 休職中も原則として権利は維持される。ただし、他者の開発を著しく妨げる場合や公共上の必要がある場合は、本人への通知と事情確認を経て変更・取消しを検討できる。

9. 権利の変更・取消しを検討する場合、原則として事前通知と説明・改善の機会を設ける。

10. 重大な違反や緊急の安全対策が必要な場合、運営は一時的に権利を制限できる。 この場合、可能な限り速やかに本人へ理由を説明する。

第7条（開発区域および他者の成果物）

1. Builder は、他者が開発・管理する区域、建築物、設備、交通インフラを尊重する。

2. 他者の成果物を変更、移動、撤去、改修する場合は、原則として権利者の許可を得る。

3. 権利者が不明、または連絡不能の場合は運営に相談する。

4. 安全確保や重大な障害への緊急対応は、運営の判断で必要な範囲に限り実施できる。

5. 権利に関する紛争は第 20 条に従う。

第8条（所有者表示）

1. Builder は必要に応じて、建築物、路線、施設などに所有者・管理者を示す看板等を設置する。

2. 表示には Builder 名、組織名など管理主体を特定できる情報を用いる。

3. 公共性が高い施設や管理者の確認が必要な対象については、運営が合理的な理由を示して表示を求めることができる。

4. 表示がないことのみを理由に権利が失われることはない。

5. 所有者が不明な場合、運営は記録、設置経緯、周辺状況などを確認して対応を決定できる。

第9条（Schematic の登録および共有）

1. Builder は、自ら制作した建築物、または他者への利用許諾に必要な権限を有する建築物等を Schematic として登録できる。

2. 登録は、Discord 等の指定された「建物一覧」に建物名、完成写真、制作者名などの必要情報を投稿して行う。保存名は原則として登録名と統一する。

3. 登録者は、登録対象について MJX 内での設置、複製、改変および他の Builder による利用を許諾できる権限を有していなければならない。

4. 登録した Schematic は、登録時に明示した条件の範囲内で、他の Builder による MJX 内の都市開発目的での利用を許諾したものとする。

5. 前項の許諾には、原則として次の行為を含み、設置ごとの個別許可は不要とする。

・MJX 内での設置・利用・複数箇所への設置・景観や用途に合わせた外装・内装・設備の変更

6. 登録時に追加条件や制限を設ける場合は、他の Builder が利用前に確認できるよう明示する。ただし、本規定と矛盾する条件は運営の確認を必要とする。

7. 未登録の Schematic は、制作者または正当な権利者の許可なく使用・設置してはならない。

8. 他者の著作物や、登録・再利用を許諾する権限のないデータを無断登録してはならない。

9. 大幅な改変を加えて別の建物として再登録する場合は、原則として元の制作者を明記する。ただし、正当な理由がある場合は運営と協議できる。元の制作者について誤認させる表示は禁止する。

10. 通常の設置・軽微な改変における制作者表示は、登録時に別途条件が定められている場合を除き任意とする。

11. 登録者は、運営への申出により登録を解除し、将来の新規利用を停止できる。

12. 登録解除前に設置された建物や、既に取得・配置された Schematic は原則として撤去・回収しない。ただし、登録解除後に新たな建築物を設置することは、既にデータを保有している場合も含め、原則として認めない。

13. 登録解除時に進行中の開発案件については、進捗状況や関係者への影響を考慮し、運営が継続の可否を判断する。

14. 権利侵害、重大な規定違反などが確認された場合、運営は利用停止、撤去など必要な措置を講じることができる。

第10条（Create Mod および技術設備）

6. 負荷や障害が確認された場合、運営は対象設備の停止、変更、撤去などを求めることができる。

7. 緊急時は一時的に制限できるが、可能な限り速やかに理由を説明する。

8. 鉄道の構築には、原則として MTR Mod を主要システムとして使用する。

第3章 経済活動および禁止事項

4. 単にデザインが独特であることや、担当者の個人的な好みに合わないことだけを理由に禁止してはならない。

5. 運営は、判断の一貫性を確保するため、許可・不許可事例や判断基準を記録し、必要に応じて公表する。

8. 単なる意見の相違や合理的な運営批判のみを理由に、違反と判断してはならない。

第4章 活動の休止および脱退

第15条（活動状況の確認）

1. 運営は、資格・権限の維持、担当案件の引継ぎ、運営上の問題解決などを目的として、Builderの活動状況や管理対象を確認できる。

2. 確認時は、可能な限り目的と回答期限を明示する。

3. 無回答のみを理由に直ちに資格を取り消してはならない。

4. 長期間連絡が取れず、運営上の支障が生じる場合は、第 16 条・第 17 条に従って対応できる。

第16条（休職）

1. Builder は合理的な理由がある場合、運営へ休職を申請できる。可能な範囲で理由と予定期間を記載する。

2. 承認された休職期間中は、通常の活動義務を一時的に免除する。権限、優先保有権、担当案件の取扱いは本規定に従う。

3. 休職中に権限や担当案件について確認する場合、原則として通知から 7 日以上の回答期限を設ける。ただし、緊急性など合理的な事情がある場合は調整できる。

4. 期限までに回答がない場合、運営は追加連絡や事情確認に努め、直ちに休職・資格を取り消さない。

5. 実質的な活動・連絡の双方が原則 60 日以上確認できない場合、権限や担当案件の維持について審査できる。

6. 審査では、休職申請、事前連絡、本人の事情、案件の状況などを考慮する。承認済みの休職や合理的な事情がある場合は、単純に無活動期間だけで判断しない。

7. 定期的な連絡がある場合も、管理対象の状況や開発への影響に応じて必要な確認を行うことができる。

8. 休職回数、期間、再申請間隔の制限は、必要に応じて別途定めて周知する。

第17条（路線の長期休止）

1. 路線の建設、整備、運行などの実質的な活動が原則 60 日以上確認できない場合、運営は路線の状況や今後の計画を確認できる。

2. 完成して正常に運行・管理されている路線は、建設作業がないことのみを理由に休止と判断しない。

3. 休職、事前申告、技術的問題など合理的な事情がある場合は、それらを考慮して判断する。

4. 運営は所有者に説明や計画の提示を求められるが、活動停止のみを理由に直ちに権利を剥奪・強制撤去してはならない。

5. 所有者が現役 Builder でない場合は、本人の状況、既存の権利、路線の公共性、引継ぎの必要性を考慮し、管理継続、譲渡、共同管理などを検討する。

6. 譲渡先が協議で決まらない場合、運営は希望者の募集、調整、抽選など合理的な方法で決定できる。

7. 権利変更・取消しの際は、原則として事前通知と説明の機会を設ける。

8. 安全・公共上の緊急時は、一時的な管理変更など必要な措置を行える。

第18条（脱退および登録データの取扱い）

1. 脱退する Builder は運営へ通知する。

2. 権限、担当案件、優先保有権、Schematic、リソースパックなどは本規定および関連手続きに従って処理する。

3. 運営は通知から原則 14 日以内を目安に必要な確認・手続きを進める。

4. 本人と連絡が取れない、または協力が得られない場合、合理的な期間を設けて連絡を試みたうえで対応を決定できる。

5. 登録済み Schematic の取扱いは第 9 条に従う。脱退のみを理由に、既存の利用許諾が当然に消滅するものではない。

6. リソースパック、モデル、テクスチャ、音声などのデータは、制作者・権利者との利用許諾条件および関連規定に従う。

7. リソースパック等の登録・提供に際しては、使用、改変、再配布、脱退後の継続利用などの許諾範囲を明確にする。

8. 参加・脱退の事実のみを理由に、権利者の許諾なくデータを継続使用できるものとはしない。

権利者が利用停止を求めた場合は、既存の許諾条件、第三者の権利、既設施設への影響などを確認して対応する。

9. 脱退のみを理由に既設の建築物・路線が自動撤去されることはない。

10. 権利侵害、重大な規定違反など合理的な理由がある場合、運営は必要な措置を講じることができる。

第5章 処分および紛争解決

第19条（処分および手続き）

1. 運営は規定違反に対し、違反内容、影響、故意・過失、過去の違反歴、改善状況などを考慮して必要な措置を決定できる。

2. 措置には、注意、警告、改善要求、設備修正要求、アイテム・コインの回収、権限の一時停止、Builder 資格取消しなどを含む。

3. 権限停止や資格取消しなど重大な処分の前には、原則として違反内容を通知し、弁明・説明の機会を設ける。

4. 安全確保、重大な被害防止、証拠保全など緊急時は、事前の説明機会なしで一時的に制限できる。この場合、可能な限り速やかに理由を通知し、事後に説明の機会を設ける。

5. 重大な処分では、処分内容、理由、適用規定を本人へ通知する。

6. 処分対象者は、原則として通知を受けた日から 14 日以内に、指定された窓口へ異議申し立てができる。ただし、合理的な事情により期限内の申立てが困難だった場合、運営は期限後も受理を検討する。

7. 処分通知には、異議申し立て窓口と期限を明示する。申立人は対象の処分と異議の理由を示す。

8. 運営は異議を受けた場合、処分の根拠、事実、本人の説明、関連規定などを再確認し、維持・変更・取消しを判断する。

9. 再審査では、可能な限り当初の処分決定に直接関与していない担当者が審査する。人員等の事情で困難な場合は、中立性を確保できる方法を検討する。

10. 異議申し立てを理由とした不利益な取扱いは禁止する。

11. 異議申し立てのみで処分は自動停止しない。ただし、運営は必要に応じて処分の一時停止、変更、解除を決定できる。

12. 緊急の安全確保に必要な制限は審査中も継続できるが、必要性を随時確認し、不要となった場合は解除・変更する。

13. MJX 共通規定第 12 条の異議申し立て制度も適用し、手続きや権限が異なる場合は第 22 条の優先関係に従う。

14. 処分の実施・記録および最終判断は、共通規定その他の関連規定に従う。

第20条（Builder 間の紛争解決）

1. Builder 間で土地、建築物、路線、Schematic、業務などの紛争が生じた場合、まず当事者間で事実を確認し、協議による解決に努める。

2. 解決できない場合は、運営へ仲裁・判断を求めることができる。

3. 運営は双方の説明、証拠、関連規定、過去の経緯などを確認して判断する。

4. 重大な妨害、権利侵害、 サーバーへの被害など緊急時は、協議を待たずに必要な措置を講じることができる。

5. 運営判断への異議は第 19 条および共通規定に従う。

第21条（共同開発）

1. 複数の Builder が共同開発する場合は、担当範囲、管理責任、成果物の利用条件、制作者表示などを可能な限り事前に合意する。

2. 成果物の権利は、当事者間の合意、各制作者の権利および関連規定に従う。

3. 合意がないことのみを理由に、他の参加者の成果物を自由に利用・変更できるものではない。

4. 権利や管理について争いが生じた場合は、第 20 条に従う。

5. 運営は必要に応じて、開発記録や担当範囲の提示を求めることができる。

MTR Japan Nexus 経済規定

2026 年10 月5 日制定

MTR Japan Nexus

第1章 総則

第1条（目的）

本規定は、MTR Japan Nexus（以下「MJX」という。）における経済活動について必要な事項を定め、参加者がMJX において生活、労働、消費及び事業活動等を行う機会を提供するとともに、健全かつ継続的な経済運営を行うことを目的とする。

第2条（基本原則）

1. MJX における経済活動は、参加者が自由に商品、サービス及び労働を提供できることを基本とする。

2. MJX は、参加者が最低限の生活及び活動を行えるよう、必要な公共サービスを提供する。

3. 公共事業は、参加者に最低限必要な商品及びサービスを安定して提供することを目的とし、高い品質、速度、頻度、利便性その他の付加価値を提供することを目的としない。

4. 民間事業者は、公共サービスを基準として、品質、速度、頻度、利便性、設備、付加価値その他の要素により独自のサービスを提供することができる。

5. 管理者は、MJX の経済の安定及び継続性を確保するため、必要に応じて価格、賃金その他の経済条件を定め、又は変更することができる。

第3条（用語）

本規定において、次の各号に掲げる用語は、それぞれ以下の意味を有する。

1. 「管理者」：MJX の管理者として権限を有する者をいう。

2. 「最高管理者」：MJX における最高管理権限を有する者をいう。

3. 「参加者」：MJX に参加するすべての者をいう。

4. 「ビジター」：MJX において、都市生活、経済活動その他の一般的な参加活動を行う者をいう。

5. 「ビルダー」：MJX の都市、建築物、交通施設その他の開発及び建設を主たる活動として行う者をいう。

6. 「事業者」：MJX において商品又はサービスを継続的又は反復的に提供する者をいう。

7. 「公共事業」：管理者がMJX の参加者に対して最低限必要な商品又はサービスを提供するために行う事業をいう。

8. 「私営事業」：管理者その他の参加者が自己の事業として行う事業であって、公共事業に該当しないものをいう。

9. 「労働」：事業者の指示又は管理の下で、時間又は作業を提供し、その対価として賃金を受ける活動をいう。

10. 「建築請負」：建築物、施設その他の成果物について、完成した成果物を提供することを目的として報酬を受ける契約をいう。

第2章 ビルダー及びビジター

第4条（ビルダーの活動）

1. ビルダーは、MJX の都市開発及び建築活動を行うことを主たる目的として活動する。

2. ビルダーによる通常の都市開発及び建築活動については、原則として本規定に定める商品購入、賃金、住宅、労働その他の経済的制約を適用しない。

3. ビルダーは、都市開発上必要な範囲において、Creative 環境その他管理者が認めた環境を利用することができる。

4. ビルダーによる通常の都市開発及び建築活動に必要な建築資材、工具その他の資源は、原則として経済取引の対象としない。

第5条（ビルダーの経済活動）

1. ビルダーであっても、店舗の運営、商品の販売、サービスの提供、労働者の雇用その他の経済活動を行う場合には、その活動について本規定を適用する。

2. ビルダーが自らの建築技術又は作業を他者に提供し、完成した成果物その他の成果に対して報酬を受ける場合には、原則として建築請負として扱う。

3. 建築請負については、通常の雇用労働に関する賃金及び労働時間の規定を原則として適用しない。

4. ビルダーであることのみを理由として、経済活動を行う場合の義務を免除するものではない。

5. 前各項にかかわらず、建築請負の実態が事業者の指示又は管理の下で時間単位の労働を行うものである場合は、通常の労働として扱うことができる。

第6条（ビジターの活動）

1. ビジターは、MJX において労働、事業、消費、居住その他の経済活動を行うことができる。

2. ビジターによる通常の経済活動には、本規定を適用する。

3. ビジターが都市開発又は建築活動を行う場合、必要な資材その他の物品について、公共事業又は私営事業を通じて取得することができる。

第3章 通貨及び初期資金

第7条（通貨）

1. MJX における経済活動には、原則として「G」を使用する。

2. G は、MJX 内における商品、サービス、労働その他の経済活動の対価として使用する。

3. G の発行、配布その他の通貨量に影響する行為は、原則として管理者が管理する。

第8条（G の発行及び管理）

1. 管理者は、公共事業、報酬、補償、初期支給その他MJX の運営上必要な場合にG を発行又は配布することができる。

2. 管理者は、G の過剰な発行によるインフレーションその他の経済上の問題を防止するため、必要に応じて発行量を調整することができる。

3. 管理者が経済状況に重大な影響を与える規模のG を新たに発行する場合、その理由及び目的を記録するものとする。

第9条（初期支給）

1. MJX に参加したビジターには、原則として以下を初期支給する。

・パン：1 スタック（64 個）・2,000G

2. 初期支給の内容は、経済状況その他の事情により管理者が変更することができる。

3. ビルダーについては、通常の初期支給を行わないことができる。

第4章 公共事業及び価格

第10条（公共事業）

1. 管理者は、MJX において参加者の最低限の生活及び活動に必要な商品又はサービスについて、公共事業を行うことができる。

2. 公共事業は、最低限の生活及び活動を保障することを目的とする。

3. 公共事業は、利益の最大化又は民間事業者を上回るサービスの提供を目的としない。

4. 公共事業の範囲は、管理者が必要に応じて定めるものとする。

5. 公共事業は、最低限の目的を達成する範囲において、品質、速度、頻度、利便性その他の面で簡素又は限定的なサービスとなることを妨げない。

第11条（公共価格）

1. 管理者は、公共事業として提供する商品又はサービスについて、公共価格を設定することができる。

2. 公共価格は、当該商品又はサービスについてMJX 内で必要とされる最低限のサービス水準を維持するための基準価格とする。

3. 公共価格は、経済状況、提供費用、利用状況その他の事情に応じて管理者が変更することができる。

4. 管理者が公共価格を設定した商品又はサービスについて、私営事業者は、原則として公共価格を下回る価格で提供してはならない。

5. 前項にかかわらず、管理者が特に認めた場合はこの限りでない。

第12条（食料品）

1. 公共事業として提供するパンの価格は、6 個につき150G とする。

2. 管理者は、経済状況その他の事情に応じて前項の価格を変更することができる。

3. パン以外の食料品についても、管理者が公共価格を設定した場合は、前条の規定を適用する。

4. 管理者が公共価格を設定していない食料品については、事業者が自由に価格を設定することができる。

第13条（私営事業者の価格）

1. 私営事業者は、公共価格が設定されている商品又はサービスについて、公共価格以上の範囲で自由に価格を設定することができる。

2. 私営事業者は、価格のほか、品質、速度、頻度、利便性、設備、立地、付加価値その他の要素によって公共事業との差別化を図ることができる。

3. 私営事業者が公共事業と同一又は同等の商品若しくはサービスを提供する場合であっても、公共事業と同一の品質、速度、頻度又は利便性を提供する義務を負わない。

第5章 住宅

第14条（公共住宅）

1. 管理者は、参加者が最低限の居住環境を確保できるよう、公共住宅を提供することができる。

2. 公共住宅の家賃は、原則として1 か月10,000G とする。

3. 公共住宅の設備及びサービスは、最低限の居住に必要なものを基準とする。

4. 公共住宅は、高級性、快適性その他の付加価値を提供することを目的としない。

第15条（公共住宅の取得）

1. 公共住宅について、入居者が12 か月間継続して家賃を支払った場合、当該住宅を取得できる制度を設けることができる。

2. 前項の取得制度を実施する場合、所有権、土地の扱い、改築、譲渡、売却その他必要な条件を管理者が別途定めるものとする。

3. 管理者は、経済状況又は住宅制度の変更に応じて、取得制度を変更又は停止することができる。

第16条（私営住宅）

1. 私営事業者は、住宅その他の建築物を提供することができる。

2. 私営住宅の価格及び契約条件は、MJX の規定に反しない範囲で事業者が定める。

3. 私営住宅については、価格、広さ、設備、立地その他の付加価値を自由に設定することができる。

4. 私営住宅について公共価格が設定されている場合は、第11 条及び第13 条の規定を適用する。

第6章 交通

第17条（公共交通）

1. 管理者は、参加者がMJX 内を移動するための最低限の交通手段として、公共交通を提供することができる。

2. 公共交通は、区役所その他の主要な公共施設等へ移動できる最低限の交通手段を確保することを目的とする。

3. 公共交通は、必ずしも高い速度、運行頻度、利便性、快適性その他の付加価値を提供することを目的としない。

4. 公共交通は、最低限の目的を達成する範囲において、簡素又は非効率な運行となることを妨げない。

第18条（公共交通の運賃）

1. 公共交通の最低運賃は、原則として100G とする。

2. 管理者は、路線、距離、利用状況、運行条件その他の事情に応じて運賃を設定することができる。

3. 管理者は、経済状況及び交通事情に応じて運賃を変更することができる。

第19条（私営交通）

1. 私営事業者は、公共交通とは別に交通サービスを提供することができる。

2. 私営交通の価格は、本規定その他管理者が定める価格条件に反しない範囲で、事業者が定めることができる。

3. 私営交通は、速度、運行頻度、利便性、快適性、設備、運行範囲その他の付加価値によって公共交通との差別化を図ることができる。

第7章 建築資材及び工具

第20条（基本建築資材）

1. 管理者は、ビジターその他必要とする参加者に対し、建築活動に必要となる基本的な建築資材を販売することができる。

2. 基本建築資材は、原則として1 スタック（64 個）単位で販売する。

3. 販売価格は、管理者が経済状況その他の事情を考慮して定める。

4. ビルダーの通常の都市開発及び建築活動については、本条による資材購入を必要としない。

第21条（工具）

1. MJX への参加時に、ビジターに対して活動に必要となる基本的な工具を無償で提供することができる。

2. 基本工具より性能の高い工具、特殊な工具その他の追加設備については、有償とすることができる。

3. ビルダーについては、Creative 環境等を利用する場合、通常の工具の無償提供を必要としない。

4. 管理者は、ゲームバランス及び経済状況を考慮して、無償提供する工具の種類を変更することができる。

第8章 賃金及び労働

第22条（賃金の基本）

1. MJX において労働を行った者には、原則としてその労働に応じた賃金を支払うものとする。

2. 賃金は、G によって支払うものとする。

第23条（建築請負）

1. ビルダーその他の参加者は、建築物、施設その他の成果物について、報酬を受けて建築請負を行うことができる。

2. 建築請負における報酬、成果物、納期、仕様その他の条件は、当事者間で事前に合意するものとする。

3. 建築請負は、原則として通常の雇用労働とは区別する。

4. 建築請負の報酬については、第24 条の最低賃金及び第25 条の最高賃金を直接適用しない。

5. 建築請負の実態が事業者の指示又は管理の下で時間単位の労働を行うものである場合は、通常の労働として扱うことができる。

第24条（最低賃金）

労働に対する賃金は、原則として1 時間あたり1,000G を下回ってはならない。

第25条（最高賃金）

1. 労働に対する賃金は、原則として1 時間あたり10,000G を超えてはならない。

2. 前項の上限は、MJX 内における過度な通貨流入及び経済の不安定化を防止することを目的とする。

3. 管理者が特別な事情を認めた場合は、第1 項の上限を一時的に変更することができる。

第26条（賃金の計算）

1. 賃金は、原則として10 分単位で計算する。

2. 1 時間あたり1,000G の労働については、10 分あたり約167G を基準とする。

3. 事業者は、10 分単位で計算可能な範囲において、具体的な賃金額を求人時に明示しなければならない。

第9章 雇用

第27条（雇用条件の明示）

事業者が労働者を雇用する場合、求人時に以下の事項を明確にしなければならない。

1. 雇用条件

2. 賃金

3. 業務内容

4. 必要となるその他の条件

第28条（雇用人数）

1. 事業者が同時に雇用できる労働者は、管理者が別途定めない限り、原則として3 人までとする。

2. 管理者は、事業規模、利用状況、公共性その他の事情を考慮し、前項の人数制限を変更することができる。

3. 事業者は、労働者が他の事業者で働くことを妨げてはならない。

4. 事業者は、労働者に対して自らの事業者への加入又は専属的な勤務を強制してはならない。

第29条（労働時間）

1. 1 回の労働時間は、原則として10 分以上3 時間以内とする。

2. 管理者が必要と認めた場合は、前項の上限を超えて労働させることができる。

3. 長時間の労働を行う場合、事業者は求人時にその旨を明示するものとする。

第30条（賃金の支払）

1. 事業者は、労働終了後3 日以内に賃金を支払わなければならない。

2. 労働者から賃金の未払いについて申告があった場合、管理者は必要に応じて事実確認を行うことができる。

3. 未払いが確認された場合、管理者は必要に応じて当該賃金を立て替えて支払うことができる。

4. 前項の場合、賃金を支払わなかった事業者は、原則として30 日間、新たな労働者を雇用することができない。

第31条（雇用記録）

1. 事業者は、労働者を雇用した場合、以下の事項を記録しなければならない。

・事業者名・労働者名・業務内容・労働時間・賃金

2. 雇用記録は、原則として一般公開する必要はない。

3. 管理者から雇用記録の提出を求められた場合、事業者は3 日以内に提出しなければならない。

4. 雇用記録を作成しない、又は必要事項を記録していない事業者については、管理者は原則として14 日間、新たな労働者の雇用を制限することができる。

第10章 事業者及び取引

第32条（事業者の活動）

1. MJX において、参加者は商品又はサービスを提供する事業を行うことができる。

2. 事業者は、MJX の規定に反しない範囲で、その事業内容、サービス内容及び価格を定めることができる。

3. 事業者は、他の事業者と競争し、又は協力することができる。

第33条（公共事業との関係）

1. 公共事業は、MJX における最低限のサービスを提供することを目的とする。

2. 公共事業は、私営事業者と同等以上の品質、速度、頻度又は利便性を提供することを必須としない。

3. 私営事業者は、公共事業よりも高い品質、速度、頻度、利便性その他の付加価値を提供することにより、独自の需要を獲得することができる。

4. 公共事業が最低限のサービスを提供している限り、そのサービスが私営事業者より非効率又は不便であることのみを理由として、改善を義務付けられるものではない。

第34条（個人間取引）

1. 参加者は、他の参加者との間で商品、サービス及びG の取引を行うことができる。

2. 個人間取引における価格及び条件は、当事者間で合意するものとする。

3. 取引の内容について、虚偽の説明、意図的な未履行その他相手方を欺く行為を行ってはならない。

第35条（市場の公正）

1. 参加者は、他の参加者の正常な経済活動を不当に妨害してはならない。

2. 商品又はサービスの大量買占め、意図的な供給停止、価格操作その他、MJX の経済を不当に混乱させる行為を禁止する。
