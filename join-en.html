How to Join MJX

Follow these easy steps to prepare Minecraft, start the server when needed, and connect to MJX.

View StepsBuilder Eligibility
Early access is currently in effect

Please obtain the MJX modpack by following the instructions from MJX management. If there is no public download link, ask in the official Discord.

STEP BY STEP

Joining the Minecraft Server

Seven simple steps. First, prepare the modpack and Prism Launcher.

  1. 01

    Get the MJX modpack

    Download the modpack provided by MJX management. During early access, follow the administrator's distribution instructions.

    Only use the modpack version provided by MJX management.
  2. 02

    Install Prism Launcher

    Download and install Prism Launcher from the official website, then open it. Sign in to your Minecraft account if required.

    Download Prism Launcher
  3. 03

    Import the modpack

    In Prism Launcher, select “Add Instance” → “Import,” then choose the modpack ZIP from step 1. Follow the on-screen instructions.

    Import the ZIP directly unless MJX management tells you otherwise.
  4. 04

    Launch Minecraft

    Double-click the imported MJX instance in Prism Launcher. The first launch may take extra time while downloading the required files.

    If prompted to download missing mods, follow the instructions shown by the launcher.
  5. 05

    Start the server from Discord

    In the official MJX Discord, run the command below if the server is offline. If it is already running, continue to step 6.

    /start command

  6. 06

    Check server status

    When the server starts successfully, a status notification like the example below will appear in Discord. Use the latest connection address shown in that notification.

    🎉 Server started

    The server has started successfully!

    🌐 Connection address (playit.gg)
    <address shown in Discord>

    Example only. Always use the address from the latest successful server status notification in Discord.

  7. 07

    Join from Minecraft

    Open Minecraft → “Multiplayer” → “Add Server.” Enter the address from step 6 into the server address field, save, and join!

    If the connection fails, check whether the server is running and confirm that the address matches the latest status notification.
BUILDER / VISITOR

Want to Become a Builder?

The MGSA common exam is not required for visitors. Builder eligibility is handled separately as outlined below.

VISITOR

Visitor

You may join after reviewing the applicable MJX rules. The MGSA common exam is not required. Building permissions are limited.

NEW BUILDER

New Builder

New Builder applicants must pass the MGSA common exam. After passing, request verification of your qualification from MJX management.

MGSA Common Exam Guide
LEGACY BUILDER

Builder from a former server

Former Builders of MTTS, MJaS, or JNC are exempt from the MGSA common exam. Their MJX Builder status can be carried over after verification.

All participants must follow the applicable MJX rules. Recognition of a former server's Builder status applies only within MJX; it does not itself grant an MGSA qualification.

Troubleshooting

Can't get or import the modpack? Check the instructions given by MJX management.

Minecraft won't launch? Save the Prism Launcher error message and ask for help in the official Discord.

Can't connect? Check the latest server-status notification and connection address.
